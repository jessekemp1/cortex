## Elevator Pitch

**Converx is a cognitive exoskeleton that turns information overload into strategic clarity, helping you make better decisions by orchestrating your projects, goals, and context into actionable next steps with calibrated predictions.**

---

## Problem Statement

### The Information Overload Crisis

You have more information than ever:
- Multiple active projects generating commits, issues, PRs
- Goals scattered across documents, task lists, mental notes
- Context spread across codebases, docs, conversations
- Tools promising productivity but adding complexity

Yet you have less clarity than ever:
- **Decision paralysis**: Too many options, no clear criteria
- **Priority confusion**: Everything feels urgent, nothing feels important
- **Context switching**: Jumping between domains without integration
- **Pattern blindness**: Repeating mistakes because you don't see them

### The AI Collaboration Gap

AI tools excel at:
- Executing tasks (code generation, data analysis)
- Answering questions (search, retrieval, synthesis)
- Managing workflows (automation, scheduling)

But AI tools don't help with:
- **Strategic thinking**: "What should I do next?" not "How do I do this?"
- **Cross-domain awareness**: How work decisions affect health, finance, relationships
- **Pattern recognition**: Learning from YOUR history, not generic advice
- **Calibrated prediction**: Knowing what's likely, not just what's possible

**The gap**: We have AI that can execute. We need AI that can **strategize**.

---

## Solution Overview

### What Converx Does

Converx orchestrates your existing tools and data into a unified strategist interface:

1. **Scans** your projects (git repos, activity, blockers)
2. **Parses** your goals (ACTION_PLAN.md, priorities, status)
3. **Generates** strategic recommendations (next actions, rationale, effort estimates)
4. **Predicts** needed context (files, docs, knowledge base)
5. **Formats** everything into clear, actionable output

**Single command**: `converx next` → Strategic clarity

### How Converx Works

```
┌─────────────────────────────────────────────────────────┐
│                    converx CLI                          │
│  (converx next [PROJECT])                               │
└────────────────────┬────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────┐
│              ConverxOrchestrator                        │
│  - Calls ai_intelligence.py (project activity)          │
│  - Calls goal_parser.py (goals)                         │
│  - Calls recommendation_engine.py (recommendations)     │
│  - Calls context_intelligence.py (context)             │
│  - Formats output as strategist response               │
└─────────────────────────────────────────────────────────┘
```

**Key Insight**: 80% of functionality already exists. Converx is a thin orchestration layer that unifies it.
