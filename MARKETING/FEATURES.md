# Cortex Features

**Complete feature list and benefits**

This document provides a comprehensive list of Cortex features and their benefits.

---

## Core Features

### Portfolio Memory

**What**: Cross-project patterns, lessons, and metadata storage

**Benefits**:
- Reuse successful patterns across projects
- Learn from past mistakes
- Track project metadata and health
- Compound learning over time

**Use Cases**:
- Find similar work from other projects
- Apply proven patterns to new projects
- Prevent repeated mistakes
- Track portfolio-wide metrics

---

### Session Intelligence

**What**: Automatic git-based context generation

**Benefits**:
- Automatic context on every session
- Goal inference from commits
- Focus detection (Testing, Feature dev, etc.)
- No manual context setup

**Use Cases**:
- Morning briefing with current context
- AI agent context injection
- Session hooks for automation
- Focus area detection

---

### Spec Knowledge Base

**What**: Semantic search across all project documentation

**Benefits**:
- Find relevant documentation instantly
- Semantic search (meaning-based, not keyword)
- Cross-project documentation search
- Automatic indexing

**Use Cases**:
- Search for similar specifications
- Find implementation examples
- Discover design patterns
- Reference past work
