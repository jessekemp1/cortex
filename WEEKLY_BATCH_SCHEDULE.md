- 🔗 Reference previous batch results for continuity
- ⏰ Schedule high-priority tasks with shorter deadlines (12-15 hours)
- 💾 Save batch results to project docs for team reference

## 🚀 Execution Commands

### Daily Batch Submission Template:
```bash
cd /Users/jesse.kemp/Dev/cortex

# Schedule task for tonight
python batch_cli.py schedule "Task Title" \
    --prompt "Detailed analysis prompt..." \
    --priority medium \
    --deadline-hours 15

# View what's scheduled
python batch_cli.py list --status pending

# Manual submit if needed (else auto at 6 PM)
python batch_cli.py submit
```

### Daily Results Check Template:
```bash
# Morning: Check completed tasks
python batch_cli.py check

# View results
python batch_cli.py list --status completed --days 1

# View usage stats
python batch_cli.py stats --days 7
```
