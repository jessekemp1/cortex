# Cortex Research Directives

Human-authored priorities for autonomous research scanning.
Follows the Karpathy autoresearch pattern: define what matters, let the system scan.

## Research Priorities

### Priority 1: Existential Threat Monitoring
1. **Anthropic native memory API** — If Claude gets built-in persistent memory, Cortex's memory layer becomes redundant
2. **Mem0 adds orchestration** — If Mem0 ships task routing alongside memory, direct competitor
3. **OpenAI Assistants v3** — Persistent threads + tool use could replicate supervisor pattern
4. **Claude Code competitors** — Cursor, Aider, Codex CLI evolving toward orchestration

### Priority 2: Capability Amplification
1. **Trajectory memory** — Learn from HOW tasks were solved, not just outcomes
2. **Memory admission control** — Decide what NOT to remember (avoid noise accumulation)
3. **Multi-agent coordination patterns** — New research on agent handoff protocols
4. **Tool use improvements** — Better function calling, structured outputs

### Priority 3: Ecosystem Intelligence
1. **Weather model improvements** — New NWP models, ensemble techniques for Vortex
2. **Trading signal research** — Novel alpha factors, market microstructure for Alpha Arena

## Constraints
- Scan frequency: daily batch, not real-time
- Source priority: arXiv, GitHub releases, official blogs > social media
- Signal threshold: only surface items that could change architecture decisions
