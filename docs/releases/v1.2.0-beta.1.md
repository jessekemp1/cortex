# Cortex v1.2.0-beta.1

First shippable beta. The goal for this release: **easy to set up** (≤15 minutes
to a working agent-memory loop) and **quick to prove value**, shipped only behind
a 10-point confidence gate.

> **Beta, git-clone-only.** No PyPI wheel yet (tracked by a non-blocking CI
> canary). Install by cloning the repo and running `./install.sh --yes`.

## What's new

- **Crash-proof memory loop.** The core memory-loop MCP tools run in-process — no
  running bridge daemon required. Decision writes append directly with a spool
  fallback, so a decision is never lost to a dead bridge.
- **≤15-minute setup.** `./install.sh --yes` is fully non-interactive and needs
  **no API key** on the golden path. It auto-runs init → MCP registration →
  onboard → `doctor --fix` and ends with a 3-step epilogue.
- **`.env` actually works.** The CLI and MCP server now load `~/.cortex/.env`
  (and a repo `.env`), so a key saved at install time is read without a shell
  export. Real environment variables still win.
- **`cortex doctor` you can trust.** Broader checks (server extra, in-process MCP
  import, MCP registration, PYTHONPATH, env/.env parity, hooks, launchd),
  `--json` for agent runbooks, honest exit codes (real failures exit non-zero;
  a missing key / down bridge is a WARN, not a failure), and `--fix` that repairs
  the repairable (spool flush, state dir, `.env`, MCP registration).
- **`cortex stats` — value receipts, real data only.** Decisions, recalls,
  outcome links, and recommendation follow-rate. Any rate from fewer than 10
  samples renders as "too few to rate" — never a fabricated percentage. Day 1
  shows a milestone checklist, not fake numbers.
- **Smallest credible surface.** Five always-on MCP tools
  (`cortex_intelligence`, `cortex_record_decision`, `cortex_outcomes`,
  `cortex_service_health`, `cortex_doctor`); everything else is behind
  `CORTEX_EXPERIMENTAL=1`. Experimental CLI commands exit cleanly with a clear
  message instead of a traceback.
- **One onboarding doc:** `docs/GETTING_STARTED.md` (agent-guided runbook +
  one-liner install).
- **`cortex reset` / `uninstall.sh`** for a clean teardown.

## Honesty fixes

- Removed hardcoded/fabricated metrics from user-facing surfaces (TUI learning
  accuracy, `/v2/outcomes/stats` — was an always-501 stub — daily cost, commit
  recency). All now derive from real data or show an honest empty state.
- The README test badge tracks the enforced CI floor, not a hand-counted number.

## Known limitations

- **Retrieval precision is not yet tuned.** Recall may surface loosely-related
  items. Stated plainly rather than hidden — the write path is durable; ranking
  quality is the next area of work.
- **Git-clone-only.** No published wheel for this beta.

## Install

```bash
git clone <repo-url> cortex && cd cortex
./install.sh --yes
# then restart Claude Code so it loads the Cortex MCP server
cortex demo      # prove the loop, no API key needed
cortex stats     # see your receipts accrue
```

Full walkthrough: `docs/GETTING_STARTED.md`.

## Reporting issues

Beta cohort is capped. Please include the output of `cortex doctor --json` with
any issue.

## Rollback

`git checkout v1.1.0`. The state files 1.2 adds (`spool/`, `recall_events.jsonl`,
`.env`) are additive and ignored by 1.1; the shared `decisions.jsonl` schema is
backward-compatible (the new `project` tag is optional).
