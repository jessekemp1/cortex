# Scenario Simulation and Pressure Test

## Best-Case Dynamics
1. Shadow learning stabilizes confidence.
2. Controlled autonomy improves queue quality.
3. Portfolio orchestration reduces opportunity-cost drift.
4. Trusted daily loop compounds decision quality.

## Pressure Scenarios
1. False confidence spiral -> calibrate + downgrade autonomy.
2. Signal contamination -> provenance filters + quarantine.
3. Trust fracture -> evidence traces + lower alert volume.
4. Operational saturation -> mission-priority routing and strict budgets.

## Design Refinements
1. Require >=2 independent signals for blocker classification.
2. Damp confidence on low-persistence signals.
3. Treat focus protection as hard constraint.
4. Keep instant rollback available.
