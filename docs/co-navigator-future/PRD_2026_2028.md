# Co-Navigator PRD (2026-2028)

## Vision
Build a predictive co-navigator that compounds execution quality, protects focus, and improves trust through measured outcomes.

## Strategic Thesis
1. Forecasting quality is the new productivity multiplier.
2. Trust is earned through calibration, not confidence rhetoric.
3. Focus is a finite strategic resource and must be actively protected.
4. Compounding intelligence emerges from outcome-grounded closed loops.

## Core Trajectory
1. Q2-Q3 2026: shadow mode -> controlled active mode.
2. Q4 2026-Q1 2027: calibrated routing + full integration.
3. Q2-Q4 2027: portfolio orchestration beats manual baseline.
4. Q1 2028: trusted second processing unit.

## Outcome Goals
1. 2x shipped throughput vs 2026 baseline.
2. 30-50% reduction in non-essential context switches.
3. >70% precision for 24h blocker prediction.
4. Rising confidence calibration quality quarter-over-quarter.
5. High recommendation acceptance with stable quality.

## High-Impact Product Pull-Ins

### 1) Decision Twin Engine
- JTBD: simulate 2-3 weekly plans before committing attention.
- User value: lower regret and faster route to high-impact outcomes.
- KPI: top-ranked twin plan beats manual plan in shipped impact/focus ratio.

### 2) Counterfactual Learning
- JTBD: quantify missed value from ignored recommendations.
- User value: convert intuition gaps into measurable learning signal.
- KPI: missed-value estimate trends down over time.

### 3) Portfolio Allocator
- JTBD: rebalance time/attention daily by risk + opportunity + strategic alignment.
- User value: less drift, more compounding work selection.
- KPI: cross-project throughput and alignment score increase.

### 4) Trust Governor
- JTBD: autonomy levels change based on reliability curves and guardrail health.
- User value: safer automation with transparent governance.
- KPI: autonomy promotions without trust incidents.

### 5) Pre-Mortem Forecasting
- JTBD: generate failure narratives before execution to route mitigations.
- User value: fewer avoidable blockers and rework loops.
- KPI: decrease in preventable high-severity incidents.

### 6) Compounding Memory Distiller
- JTBD: compress noisy interaction data into durable strategy primitives weekly.
- User value: less noise, better pattern transfer across projects.
- KPI: repeated anti-pattern frequency declines quarter-over-quarter.

## Innovation Research Tracks

### A) Causal Routing
- Move from correlational patterns to causal effect estimates for action ranking.

### B) Energy-Aware Planning
- Align deep/creative/ops work to cognitive energy state to raise quality per hour.

### C) Strategic Horizon Model
- Optimize 24h, 7d, 30d objectives jointly to prevent urgent-work capture.

### D) Human-AI Contract Layer
- Explicit policy contract for why/when AI can act, with user-overridable boundaries.

### E) Narrative Intelligence
- Keep a live strategic narrative tying roadmap, outcomes, and trust trends.

## Primary Use Cases
1. Forecasted blocker prevention.
2. Focus-preserving prioritization.
3. Overnight autonomous queue fill.
4. Cross-project routing by expected value.
5. Trust scoreboard (prediction vs actual).
6. Decision Twin weekly planning.
7. Counterfactual review in weekly retros.

## Product Principles
1. Evidence over inspiration.
2. Explainability over opacity.
3. Focus protection over alert volume.
4. Deployment conversion over endless validation.
5. Autonomy is earned by trust gates.
6. Human agency remains the final control plane.

## Non-Goals
1. Fully replacing human judgment.
2. Unbounded autonomous execution.
3. Opaque recommendation systems.
4. Optimization without measurement.

## MVP-to-Frontier Feature Sequence
1. Reliable loop and telemetry.
2. Decision Twin + Counterfactual + Allocator.
3. Trust Governor + Pre-Mortem + Memory Distiller.
4. Causal, energy-aware, horizon-aware strategic optimizer.
