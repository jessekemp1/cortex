## Validation Gates
1. Forecast precision gate (24h, 72h).
2. Calibration error gate.
3. Focus impact gate.
4. Queue quality and dedupe gate.
5. Deployment conversion gate (validated -> shipped).
6. Autonomy safety gate (Trust Governor).

## Rollback Rules
1. Focus degradation for 2 weeks -> autonomy level down.
2. Calibration spike -> freeze autonomy promotion.
3. Queue spam signals -> revert to shadow mode.
4. Trust incident severity high -> policy lockdown + postmortem.
