# Paper: Causal Routing

## Research Question
Can action ranking improve by estimating causal effect instead of correlational association?

## Approach
- Build intervention-outcome dataset from recommendation logs.
- Estimate treatment effects with robust observational methods.
- Use uncertainty-aware causal uplift in ranking policy.

## Deliverables
1. Causal graph assumptions.
2. Estimator benchmark.
3. Offline policy evaluation report.
