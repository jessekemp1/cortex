# Paper: Strategic Horizon Model

## Research Question
Can tri-horizon optimization (24h/7d/30d) reduce urgent-work capture while preserving responsiveness?

## Approach
- Define multi-horizon objective with constrained optimization.
- Assign tasks horizon labels and transition costs.
- Optimize for compounded value across horizons.

## Deliverables
1. Objective and constraints spec.
2. Simulation harness.
3. Horizon tradeoff policy.
