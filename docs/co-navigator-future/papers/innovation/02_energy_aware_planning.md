# Paper: Energy-Aware Planning

## Research Question
Does matching task type to cognitive energy state improve output quality per hour?

## Approach
- Infer energy state from session telemetry and self-tagging.
- Build task-energy compatibility model.
- Reorder day plan based on expected quality uplift.

## Deliverables
1. Energy state taxonomy.
2. Compatibility scoring model.
3. Controlled field trial design.
